# Parking spaces for SSMUH

## Summary

Use the parking default to screen whether the site plan accounts for vehicle storage. The demo uses 1 parking space per dwelling unit as the illustrative default for R1-1 SSMUH cases.

## Key numbers

- Parking rate: 1 space per dwelling unit
- Evidence: parking plan or site plan count
- Applies to: each proposed dwelling unit

## How this lands in the demo

Multiply the proposed dwelling units by 1 to find the expected parking count. Trigger `gap-parking-short` when the submitted count is lower or when the parking plan is missing.
