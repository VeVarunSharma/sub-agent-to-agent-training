# Provincial SSMUH framework

## Summary

Use the provincial SSMUH framework to place local R1-1 review in context. The demo treats the framework as an eligibility backdrop while local zoning supplies the detailed metrics.

## Key numbers

- SSMUH unit framework: up to 4 units on many restricted residential lots
- Local review: zoning metrics still govern the site-specific screen
- Evidence: zoning district, lot data, and proposed unit count

## How this lands in the demo

Confirm that the proposal sits in the SSMUH pathway before applying detailed local checks. Trigger `gap-ssmuh-eligibility-unclear` when the zoning district, lot data, or unit count does not support that pathway.
